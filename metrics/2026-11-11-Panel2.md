## Panel data and FE

Recall
$$
y_{it} = a_i + X_{it} b+e_{it}
$$

- FE => remove a and estimate b from within unit variation
- does not solve: time varying OVB, reverse causlity ...

economic arguments! 



Example: City Density and Wages on worker level
$$
\ln wage_{it} = a_i + \gamma \ln density_{c(i,t)}+ X_{it}b+ \lambda_t + e_{it}
$$

- Worker FE = remove characteristics of workers
- varation => comes from Movers
- why did the worker move? potentially time varying unobservables...



Math: OLS BLUE in panel

- linear model CHECK
- strict exogeneity $E(e_{it} | X_{it}a_i) = E(e_i) = 0$
- problem: e is autocorrelated within unit
  - past defines future
  - $Cov(e_{it}, e_{is}) \ne 0$

=> FE is unbiased but inefficient (SE are wrong)



=> **Clustered Standard Errors**

- Each unit = independent cluster
  - correlation across time within unit = allowed
  - but not across units

=> changes SE



## Random Effect Model

$a_i$ = assumed to be random

- not treated as estimatable paramter
- needs strong assumption: $E(a_i | X_{it}) = E(a_i) = 0$
  - a unrelated to outcome
  -  eg in "wage ~ a + education": hidden talent unralted to educ

$$
y_{it} = X_{it} b+u_{it} \text{ with } u_{it} = a_i+e_{it}
$$

Pooled OLS = not efficient, residuals are correlated



efficient estimator: **Generalized Least Squares** (GLS)

- similar to OLS, takes into account the structure of e
- $\hat{\beta}_{GLS} = (X' \Omega_u^{-1}X)^{-1} (X' \Omega_u^{-1}X)$
- Depends on
  - within: $\bar{y} = a+b \bar{x}_i+e_i$ = only look at unit average
  - between: $\hat{b}_{BE} = (\bar{X}' \bar{X})^{-1}(\bar{X}'\bar{y})$ = only between unit averages
- combine both, depending on information value



FE vs RE?

- FE = allows indiv. effects to be correlated 
- RE = if not that => more efficient



Test with Hausman test:

- $H_0:  E(a_i | X_i) = 0 \to$ use RE  
- $H_1:  E(a_i | X_i) \ne 0 \to$ use FE



or with Mundlak

- short: add averages $\bar{X}$ to panel regression
- if coefficient $\ne$ 0: biased
- also works with clustered SE (advantage over Hausman)



## Wrap up

- FE = usually more realistic than RE
- tests with accepting H0 = dont always solve the problem
- just because we want to know something about time-invariant variable





| Estimator  | Variaten used            | Allows $Cov(X,a) \ne 0$ | Time-invariant |
| ---------- | ------------------------ | ----------------------- | -------------- |
| Pooled     | within+between           | No                      | Yes            |
| First Diff | changes                  | Yes                     | No             |
| Within FE  | within                   | Yes                     | No             |
| RE / GLS   | within+ between          | No                      | Yes            |
| Mundlak    | Within + modeled between | Yes                     | Maybe          |

Trade off: 

- if you want time-invariant
- you need something with between 
- but then => strong assumption must hold
- Mundlak = somewhere in the middle





**Takeaways**

- Panel data = between + within variation
- FE = very useful
  - but requires within variation + credible exogeneity
- Clustered SE = adress within dependence
- RE = needs strong assumption



### Econometric Workflow

1. Describe Panel
2. Plot / summarize: within + between variation
3. State endogeneity concern
4. Decide which FE are needed
5. Check regressors
6. Estimate FE with Time
7. Cluster SE
8. Ask what time-varying endogeneity remains
