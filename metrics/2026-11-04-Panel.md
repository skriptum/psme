# 04.11.2026 Panel



## Definition 

Panel Dataset: 

- repeated observerations of same entities
- $\{ y_{it}, X_{it} \}$



Sources of Variation

- between variation = across units
- within variation = across time



**Types**

- Micro Panel T < N: individuals observed for few years
- Macro Panel T = N: countries / regions over many years



**Balancedness**

- Balanced: every unit in every period
- Unbalanced: units observed for different periods of time
  - $T_i \ne T \;\forall i$
  - Questions to ask: 
    - attrition related to outcome / regressors
    - exits, bankrupty, deaths, ...



## Fixed Effects

Control for unobserved unit characteristics in panels

Example: Beer Tax and Traffic fatalities in US States
$$
FatalityRate_{it} = a + b \ BeerTax_{it} + z_i+e_{it}
$$
$z_i$ = persistent state characteristics (road infrastructure)

if $Cov(BeerTax_{it}, z_i) \ne 0$ 

- cross sectional OLS biased!

- but panel OLS: => can be estimated!
  - if OVB does not change over time
  - then changes in y over time = not due to z



Now: Methods to assess the FEs

### First Differences

$$
y_{it} = a + b x_{it} + z_i + e_it \\
\to First \ Differences: \\
y_{it} - y_{i,t-1} = b (x_{it}- x_{i,t-1})+e_{it}-e_{i,t-1}
$$

or shorter: $\Delta y_{it} = \Delta X_{it} b + \Delta e_{it}$

OLS on this:

- $\hat{\beta}_{FD} = ( \Delta X' \Delta X)^{-1} \Delta X' \Delta y$

if $E(\Delta e | \Delta X) = 0$ => $\beta$ is unbiased

- BUT: we lose the first observation! 



### Individual Dummy Variables

Example: Beertax with 3 states (TX, CA, MA)
$$
y_{it} = a + b X_{it} + c_{CA} D_{CA,i} + c_{TX} D_{TX,i}+e_{it}
$$

- D = Dummy variables for each state
- c = coefficients of dummy variables
- MA = reference state, no dummy



Formal:
$$
y_{it} = \sum_j^N a_j d_{j,i} + X_{it}b+e_{it}
$$

- $d_{j,i}$ = 1 if j = i aka state FE
- estimate a together with b





### Within transformation

- Start: $y_{it} = a + b x_{it}  + e_it$ 

- Definte Time averages: 
  - $\bar{y} = \frac{1}{T} \sum_{t}^T y_{it}$, and $\bar{X}, \bar{e}$
- then: $\bar{y} = a_i + \bar{X}_i b + \bar{e}_i$
- Subtract $y_{it} - \bar{y}_i$
  - define as: $\tilde{y} = \tilde{X}_{it}b+\tilde{e}_{it}$
- OLS on this $\to \hat{b}_{FE}$



## Identification

What variation identifies FE coefficient (in Beer Tax)

- $\tilde{BeerTax} = BeerTax_{it} - \bar{BeerTax_i}$
- beer tax in state differs from own average
- only changes in beer tax provide variation to get *b*

if z never changes => FE is controlled, but not estimable



if states never change tax

- no within-state variation for beer-tax slope
- only contribute to state FE

ask: is there enough within-unit variation for slope / regressor of interest?



**Which method to choose?**

- within estimator = standard
- FD estimator = noisier
- depends on serial-correlation structure of e



Example:

- $\ln wage = a_i + b_1 gender_i + b_2 age_{it} + b_3 age_{it}^3 + e_{it}$
- gender = almost no switchers over time

=> leave it out, should be in FE then!



## Time Fixed Effect

$$
y_{it} = a_i+X_{it} b+\lambda_t + e_{it}
$$

= lambda = controls for time effects on all units



Note: Sometimes time and unit FE cancel out

- e.g all individuals in wage equation are observed at sime time
- age = current year - birthyear
  - current year = captured by time FE
  - birthyear = captured by unit FE

=> still controlled, but no coefficient!
