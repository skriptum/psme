# Requirements from the Guidelines

### Dataset (5 points)

- Clean, well-organized, and free of incorrect values (where feasible), missing values are
  OK, but dataset should have enough observations for your results to be credible.
- Properly labeled variables, including clear variable names and value labels (if applicable)
- Includes all relevant variables used in the analysis, with consistent coding across
  observations.



### Do File (15 points):

- Clear and well-documented, with comments explaining each section. (It is not necessary to comment each line, but clarify what is being done, i.e., Data Cleaning, Regression, Models, etc.) in each code “block”.
- Follows a logical structure: data import and merge, cleaning, construction of variables,
  descriptive statistics, and econometric analysis.
- Uses efficient commands and does not overly complicate basic codes. Codes are not
  redundant.
- Reproducible: A reviewer should be able to replicate the results entirely using the
  provided script and data – coherence, precision, and reproducibility are the hallmarks of strong econometric research
